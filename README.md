# toolars

`toolars` is a unified tools platform: a search-first public calculator
directory plus a subscription-based AI content repurposing SaaS.

The current repository is initialized as the new main repo and contains the
product/design/architecture handoff. Application code will live under `site/`.

## Layout

```text
site/      Next.js App Router application code
docs/      product, architecture, QA, migration, implementation docs
design/    design handoff, generated PNGs, extracted icons
.cdc/      CDC project context and architecture facts
specs/     CDC change specs
```
