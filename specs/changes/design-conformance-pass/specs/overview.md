# Specification Overview: design-conformance-pass

This change improves first-pass commercial design fidelity for the existing
Next.js App Router implementation.

Capabilities:

- `visual-dashboard`: home and directory surfaces express the dashboard-first
  utility model from `design/DESIGN.md`.
- `tool-card-affordances`: shared tool cards include the required information
  architecture and actions.
- `visual-qa`: representative pages receive browser-backed visual verification.

Primary source of truth:

- `design/DESIGN.md`
- `design/DESIGN-SPEC.md`

Supporting reference:

- `ui-ux-pro-max` recommendation for enterprise, trustworthy, restrained utility
  SaaS patterns.
