# Overview: merge-toolars-platform

This change establishes the approved product and technical contract for the
toolars v1 platform.

## Capabilities

| Capability | Requirement file |
|---|---|
| Product scope and IA | `specs/product/requirements.md` |
| Design system | `specs/design-system/requirements.md` |
| Public tool platform | `specs/tool-platform/requirements.md` |
| AI SaaS platform | `specs/ai-saas/requirements.md` |
| Monetization/account boundary | `specs/monetization/requirements.md` |
| i18n architecture | `specs/i18n/requirements.md` |

## Release Scope

v1 release scope includes:

- Home utility dashboard.
- All tools directory.
- AI tools directory.
- Health and finance category pages.
- All 73 calculator routes.
- Shared calculator detail template.
- AI Repurpose dashboard.
- Template Library.
- Brand Voice Manager.
- History.
- Analytics.
- Settings.
- Pricing.
- Login/register.
- Blog.
- Compare saved results.
- Static/legal pages and 404.

## Repository Boundary

Application code must live under `site/`. Documentation must live under
`docs/`. Design assets and design handoff live under `design/`.
